A frontend for the HomeApplyed home automation server written in React Native.

## Platforms
* Web
* Android
* iOS

## Features
- [x] Control Switch devices
- [ ] Control Speed/Color devices
- [ ] Control IR Devices
- [ ] Release Assets for web Android and iOS.
- [ ] Provision new devices via web
- [ ] Provision new devices via BLE
- [ ] Manage devices (rename, delete etc)
- [ ] Manage connections
- [ ] oAuth login
